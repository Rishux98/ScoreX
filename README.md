## 🚀 Tech Stack

- **Frontend:** React.js, Vite
- **Styling:** CSS3 / Tailwind CSS
- **Package Manager:** npm
- **Version Control:** Git & GitHub

## 🛠️ Getting Started

Follow these steps to set up and run the project locally.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Rishux98/ScoreX.git](https://github.com/Rishux98/ScoreX.git)
   Navigate to the project directory:
   ```

Bash
cd ScoreX
Install dependencies:

Bash
npm install
Start the local development server:

Bash
npm run dev
Open your browser and visit http://localhost:5173.

🌿 Team Workflow & Contribution Guide
To maintain a clean and conflict-free codebase, please adhere to the following Git workflow:

1. Sync with Main
   Before starting any new work, always pull the latest changes from the main branch:

Bash
git checkout main
git pull origin main 2. Create a Feature Branch
Do not commit directly to main. Create a dedicated branch for your assigned task:

Bash
git checkout -b feature/your-feature-name
Examples: feature/live-score-card, feature/auth-supabase, feature/team-stats

3. Stage & Commit Changes
   Write clear and concise commit messages:

Bash
git add .
git commit -m "Add batsman score update functionality" 4. Push and Open a Pull Request
Push your branch to GitHub:

Bash
git push -u origin feature/your-feature-name
Then navigate to GitHub and open a Pull Request (PR) into main. Request a code review from at least one teammate before merging.
